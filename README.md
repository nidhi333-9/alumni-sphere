# AlumniSphere

AlumniSphere is a full-stack web application designed to strengthen the connection between students, alumni, and administrators through a centralized platform.

The system provides three user roles:

- **Student** – Explore alumni profiles, connect with alumni, view job opportunities, and stay updated with events and announcements.
- **Alumni** – Share professional information, post job opportunities, mentor students, and engage with the college community.
- **Admin** – Manage users, monitor platform activities, approve content, and maintain the overall system.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL

## Features

- Secure role-based authentication
- Student, Alumni, and Admin dashboards
- Alumni directory and networking
- Job and internship postings
- Event and announcement management
- Responsive user interface
